Outlook signature

Install the signature

Sets up the email signature on a Windows PC. The installer doesn’t carry a copy of the signature — it downloads the current one each time it runs, so it can’t go stale.

Download the installer ZIP · ~32 KB · Windows

Four steps

  1. Close Outlook completely. The installer stops if it’s still running, because Outlook holds the signature in memory and will overwrite the new file when it exits.

  2. Unzip the download anywhere — Desktop is fine.

  3. Double-click Install-Signature.cmd. It needs an internet connection. Anything it replaces is backed up first.

  4. Open Outlook and go to File → Options → Mail → Signatures… On the right, set both New messages and Replies/forwards to Default Sig (mike@mikespear.com), then click OK.

Don’t click into the big signature editing box. Choosing the signature in the two dropdowns is safe. Typing or pasting in the edit box is not — Word rewrites the linked images as image001.png attachments, and attached images get stripped out of quoted replies. That is the exact problem this setup exists to avoid.

No scripts, if you’d rather

Close Outlook, then save these two files — keep the exact names — into %APPDATA%\Microsoft\Signatures, renaming them to Default Sig (mike@mikespear.com).htm and .txt:

  • signature-outlook.htm
  • signature-outlook.txt

The .htm is plain ASCII and survives any save path. The .txt contains a ® and two · separators; if those arrive as garbage it’s an encoding problem, and the installer handles it properly — use that instead.

Worth knowing

  • Classic Outlook for Windows only. The new Outlook and Outlook on the web store signatures in the cloud and re-embed the images, so this method doesn’t work there.
  • Swapping an image on the site updates it everywhere on its own — no reinstall needed. Only changes to the signature markup need a re-run.
  • Recipients may see blocked images until they click “download pictures.” That’s the trade-off for surviving reply chains.
To see how it renders, and the markup behind it, visit the signature reference page.

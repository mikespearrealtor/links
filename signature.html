Don’t copy and paste this into Outlook. Pasting into the Signatures edit box makes Word rewrite the images as image001.png attachments, and attached images get stripped out of quoted replies — which is the whole problem this setup avoids.

Install it by dropping the file into place instead. The raw signature lives at links.mikespear.com/signature-outlook.htm; save it (and signature-outlook.txt) into %APPDATA%\Microsoft\Signatures\ with Outlook closed, then pick it in File → Options → Mail → Signatures without clicking into the edit box. The Install-Signature.cmd helper does exactly this and pulls the current version from this domain each time it runs.

Images load from this domain, so the signature keeps working in mail already sent, and swapping a PNG here updates every machine at once.
